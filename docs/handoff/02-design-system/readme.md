# Soul to Soul — Design System

A multi-channel design system for **Soul to Soul Travel**, a Colombian boutique travel company designing intentional, experiential journeys for travelers who want depth over checklist tourism. Founded in 2020 by **Aida and Sebas**. In 2026 the company is closing **Tidur** (its five-year, 14-day flagship through Singapore, Bali and Cambodia, +150 travelers) and opening **Raíz** — on-demand journeys in Colombia for international travelers.

Brand essence: **warm, grounded, unhurried**. The voice of a trusted friend who has lived in the place — never a salesperson or wellness coach.

> **Tagline:** *Keep Seeking.*

## CREATIVE DIRECTION — the layer that keeps this from looking like a template

> An annex that governs everything below it. The visual system (palette, type, logo) is already resolved and isn't reinvented here. This layer guards something else: what makes a piece feel like Soul to Soul and **not** like a template. It applies in Claude Design and in every piece of collateral.

**Before a pixel — define what you're communicating.** Design is thinking, not decoration. Before choosing any treatment, answer in plain words: *What am I trying to say? What is the goal of this piece / section / call-out?* Three questions frame every choice that follows — **(1)** what is the single message, stated before any layout exists; **(2)** how does the viewer click with the idea *and* the brand in the same gesture (form carrying the message and reading as Soul to Soul at once, not in two separate moves); **(3)** how does this differ from everyone else (the question the final test comes back to). Then structure the message with the **Pyramid Principle** (Minto) *before* structuring the layout:

> - **Answer-first (BLUF).** Lead with the conclusion. The hero element *is* the answer, not a warm-up to it — exactly what Rule 1's “bold bet” should carry.
> - **MECE support.** Below the answer, 3–4 points that don't overlap and leave no gaps. This is what makes structure *real* under Rule 3 — sections earn their numbering only when they map these distinct arguments.
> - **SCQA setup.** For a longer piece (deck, landing page), open Situation → Complication → Question → Answer — the narrative spine that lands the reader on the conclusion.
> - **Vertical logic.** Each element answers the question the one above it raises; if a headline doesn't provoke the question its supporting line or image answers, one of the two is wrong.
>
> *(The inverted pyramid and the single-minded proposition say the same thing from other angles — decide the one message, lead with it, support it. Pick the lens; the discipline is identical.)*

**The underlying principle.** Distinction does *not* come from the colors. Cream + serif + terracotta is the same ground half the "boho" design world stands on — and the same place an AI lands by default. That isn't a flaw; it *is* the brand. But it means the distinctiveness has to be spent elsewhere: in **structure, the signature element, and the photography.** That's where the boldness goes — never into the palette.

**System layer vs. expression layer (once the objective is set).** A design system exists to *repeat*; this layer asks you to *vary*. They don't conflict once you split them:

- **System layer — repeat with discipline.** Palette, the adaptive button, header, grid, spacing scale, the Coconut↔Light background rhythm. Never improvised, never "varied for variety's sake." Consistency lives here.
- **Expression layer — vary on purpose.** How a headline is emphasized, which hero treatment, which graphic resource leads, how a section opens. This is where the boldness budget and the variation are spent.

The five rules below govern the **expression layer**; the system layer stays rigorously consistent.

1. **One bold bet per piece.** One memorable element; everything else stays simple and disciplined. Before calling a piece done, take one ornament *away*. If everything shouts, nothing is remembered.
2. **Vary the gesture — never repeat it.** Our own sanctioned device — *one accent word in italic* (see Typography) — is lovely once and a formula across twenty slides. It stays valid, but it is **one tool among several**: scale, whitespace, a single handwritten word, a photograph that carries the moment. Rotate them. Emphasis is a decision made per piece, not a mold stamped on every piece. Experiment without fear; if a move misses, correct it. The output should read as made by someone with soul — not by a machine.
3. **Structure only when it encodes something real.** Numbers, eyebrows, rules and dividers earn their place *only* when they map a true sequence, hierarchy or order the reader actually needs. Numbering sections that aren't a sequence is decoration → cut it. The same discipline governs fonts, colors, illustrations, textures and organic shapes: each one enters when it *both* communicates the message *and* builds brand identity — never as default garnish.
4. **Dose for balance.** If a piece is already loaded with illustrations, let it breathe with space, color or texture. If terracotta already carried one phrase, let it rest before it carries another. If eyebrows are already working, rest them. Playing with the elements is not the same as saturating them.
5. **The voice doesn't soften into template either.** Beyond the CONTENT FUNDAMENTALS "Avoid" list, these commercial-tourism fillers are **banned outright** — EN: *all-inclusive · all sorted · escape the stress · unforgettable experience · magical places*; ES: *todo resuelto · todo incluido · escápate del estrés · experiencia inolvidable · lugares mágicos*. Keep sentences short. Leave room for the reader to complete the emotion. Every message carries a purpose — it doesn't only sell.

**Named tells — the small AI reflexes to catch in review.** The five rules govern the big moves; these are the little decorative reflexes that slip in *even when the five rules pass*, because they aren't brand-specific — they're just what a model reaches for by default. Name them so review catches them:

- **No scroll cues.** *"Scroll ↓" · "Scroll to explore"* · a bouncing chevron at the hero foot. Composition invites the scroll; a label announcing it is filler.
- **No decorative status dots.** The pulsing *"● Live" / "● Available"* dot is garnish unless it reports real state — cut it.
- **No locale / time / weather strips.** *"Bogotá · 24°" · "Currently in Medellín, 6:14am."* Especially tempting on a travel brand, still filler. A place earns its name in the copy (specificity over vagueness), never in a decorative meta-strip.
- **No fake product UI.** A trip-planner app, booking dashboard or itinerary screen mocked from styled `<div>`s is a Tell. Lead with real photography (the primary visual focus) or a real component — never a hand-built fake screenshot.
- **No invented precision.** *"98% would return" · "4.1× more restful."* Numbers appear only when real (the +150 Tidur travelers) or labelled as example; faked precision the brand doesn't claim is data-slop.
- **Copy self-audit before ship.** Re-read every visible string — headings, eyebrows, buttons, captions, alt text, footer — and rewrite anything grammatically broken, with an unclear referent, or that reads like a model trying to sound thoughtful (forced metaphor, mock-poetic micro-copy). Unsure about a string? Replace it with a plain functional sentence. This is the string-level pass beneath the final test.

Two mechanical caps that turn rule 2 (*vary the gesture*) into something checkable:
- **Max 2 image+text split sections in a row.** The third consecutive left-image / right-text (or its mirror) is the zig-zag reflex — break it with a full-width beat, a stacked section, a carousel, or a different layout family.
- **N items = N cells.** A grid or bento has exactly as many cells as there is content for — no empty middle or trailing tile added to "balance" it. Re-shape the grid instead.

**The final test.** Before any piece is approved, one question: **Could this only be Soul to Soul?** If the same slide could belong to any other travel agency, it isn't there yet — go back to rules 1–4. **North star: less noise, more intention.**

> **Pending (Step 2): Raíz's signature element.** Rules 1 and 3 lean on a signature element that isn't defined yet. Until it exists, the "one bold bet" defaults to a strong photograph or a structural move, and rule 3's divider falls back to the ancestral symbols. Once Raíz's signature element is defined, it becomes the default answer to rule 1 and the section divider of rule 3 — wire it in then (update this section and `SKILL.md`).

## CONTENT FUNDAMENTALS — how Soul to Soul writes

**Voice:** warm and close, like a friend who lives in the place. Honest — says what it thinks even when it isn't the most sales-friendly. Reflective without being pretentious; deep without being dense. Confident, never arrogant. Capable of self-irony.

**Person & tense:** first person plural for the brand ("we design", "we believe"); second person for the reader ("you're in good hands"). Raíz is **primarily English** (international audience); Tidur was historically Spanish.

**Rhythm:** short sentences accelerate; long sentences pause. The rhythm of the copy is part of the design. *"This isn't a trip for everyone."*

**Casing:** sentence case for headings and body. Eyebrows are Avenir sustained UPPERCASE, 11px, tracked 0.2em, with no leading dash and no seal or mark (settled — a bare label). The tagline **KEEP SEEKING** is uppercase, tracked 0.4em. Never title-case marketing headlines.

**Specificity over vagueness:** *"sunrise walk in the Sierra"* beats *"unique experiences."* **Radical honesty:** the Colombia-safety FAQ goes **first**, not buried.

**Vocabulary** — *use:* balance, connection, intention, presence, rhythm, host (not guide), root, journey (not tour), capture / process / integrate, rootedness, subtle guidance, *Keep Seeking*. *Avoid:* tour, package, all-inclusive, "extreme adventure", "unique experience", "transformation" as a promised outcome, generic spa/wellness language, corporate-speak.

**Emoji:** not used decoratively. Only ever with deliberate intention (effectively never in product UI).

**Anchored copy that lives in the brand:**

- Hero: *"Modern life is good at keeping you busy, distracted, disconnected."* → *"Our journeys are designed for reconnecting to **\[yourself / nature / your purpose / the joy of living / stillness\]**."*
- FAQ close: *"Travel with intention. Come back with stories that stay."*
- Final CTA: *"Each journey begins with a conversation."*
- Newsletter: *"A slow letter, once a month."* · *"Stay close to the slow road."*

## VISUAL FOUNDATIONS

**Palette.** Five brand colors do all the work: **Coffee** `#503421` (text + deep moments), **Light** `#F7F4F0` (long-text sections), **Coconut** `#F0E8D5` (the everyday background), **Terracotta** `#A35940` (primary CTA, used as a *warm moment*, never constant noise), **Palm** `#D3C381` (secondary CTA). A separate **weathered pastel** palette (blue / ochre / coral / mint, each with a frame \~18% darker) appears **only** in the Windows of Colombia component. See `guidelines/colors-*`.

**Background rhythm.** Deliberate **Coconut ↔ Light** alternation creates breathing. **Coffee** marks deep moments (Hub Cities, Footer); **Palm** marks the single decisive moment (Final CTA). This rhythm is the backbone of every long page.

**Typography.** A **four-role system** (per the brandbook, P.30): **Milanesa Serif Light** — titles, details, logo typography; **Avenir** — body text (Book/Roman/Black); **Better Yesterday Italic** — a handwritten script for short texts, subtitles and highlights (a warm, personal accent — used sparingly); **Playfair Display** — short and long texts, subtitles and highlights (the editorial serif voice, also the documented Milanesa fallback). Display serif is for **editorial moments only** — never UI labels. **Italic is semantic, not decorative:** the rotating accent word, subtitles, tertiary links, the tagline. Headings are regular/light weight — this is a light, unhurried brand. Eyebrows are 11px uppercase tracked 0.18–0.22em.

**Imagery.** **Photography is the primary visual focus** (brandbook §04). It skews **slow-travel and aspirational** — real Colombian landscapes (large-format, high-quality, well-composed) combined with close-up details that reflect Colombian culture: hands weaving palm, coffee beans, feathers, fruit. Filters, when used, push toward **earthy tones** for a natural-organic feel; photography may occasionally carry a subtle **blue pop** drawn from sky and sea. Photos can be masked inside **organic shapes** rather than hard rectangles. A hand-painted **watercolor illustration library** (flora & fauna — jaguar, sea turtle, palm, shell, coconut, monstera) is a **secondary** resource that complements related content, never used arbitrarily. Earthy paper / watercolor / leaf-shadow **textures** sit low and quiet behind content, always within the brand palette and never competing with text.

**Instagram / social look & feel** (§06): posts mix four recipes — *solid + illustrations + icons*, *photographic*, *texture + icons*, and *solids + icons + shapes* — combining solid shapes, masks, textures and photography so the feed feels dynamic, never flat or monotonous.

**Backgrounds.** Flat brand colors and warm gradients — **no purple/blue "AI default" gradients**, no busy patterns. Generous white space ("hushpitality": calm, silence, visual rest). Major sections breathe at 100–140px vertical padding.

**Corners & cards.** Pills (999px) for all buttons and the collapsed header. Cards/panels/carousel slides at 2–4px; hub-city cards 8px; header 16px; hero video 24px. Cards are quiet and **flat** — a single 1px warm hairline (`--border-card`), never a drop shadow. **No** rounded-card-with-colored-left-border cliché.

**Elevation — flat editorial.** Depth comes from a **1px warm hairline** (`--border-card`, Coffee at \~18% on light) and surface contrast — **never shadow**. The system reads “printed on paper.” The `--shadow-*` tokens are kept as no-ops so any legacy reference degrades to flat. The one exception is the **Window** component, whose *internal* photographic shadows model real wooden shutters — that's illustration realism, not UI elevation, and stays.

**Composition rules.** Three rhythms protect legibility (specimen: `guidelines/composition-rules.html`). (1) **Illustrations never overlap a photograph** — an illustration is a secondary accent that sits *beside* a photo with at least `--illustration-clear` (32px) of space; overlaid, both get lost. (2) **Breathing room** — a text block and an adjacent illustration/media cluster always keep `--gap-component` (48px); never glued edge to edge. (3) **Carousel controls sit below** the images (centered, `--carousel-controls-gap` 24px), never beside them in the text column.

**Motion.** Slow and organic — "wood, not plastic." Hover changes are 200ms; the header pill morphs over 500ms; the **window shutters open over 1,200ms** with an organic ease, intentionally heavy. Fades + small (8px) vertical slides; no bounce, no jitter, no infinite decorative loops. All motion respects `prefers-reduced-motion`. The button arrow-reveal (primary/secondary hover) runs at 380ms — slightly slower than the standard hover so the glyph reads as arriving, not flickering.

**Hover / press.** Filled **primary** & **secondary** buttons keep their fill color on hover — a **→ arrow slides in** after the label instead (`<Button arrow>`, default `true`; reviewed in `explorations/button-colors-deep-surfaces.html`, "Flecha que aparece"). The **nav-bar CTA is the one documented exception** — it sets `arrow={false}` and keeps the earlier plain color-change hover, since a fixed header button reads better as a color shift than a moving glyph. Tertiary (editorial): the underline **erases left→right and redraws itself** — the "se borra y vuelve" treatment, no color shift. Links on Coffee → Palm. FAQ rows nudge right 8px on hover. Restraint over flourish.

**Button colors per surface (decided).** Each surface has a fixed primary/secondary pairing baked into `<Button on="…">`: **Coconut / Light** → Terracotta primary + Palm secondary. **Coffee** → Coconut-cream primary + Palm secondary (the inversion — Coffee is deep/saturated enough that Terracotta reads too close in tone, same reasoning as the Terracotta surface below). **Terracotta** → Coconut-cream primary + Palm secondary (the inversion). **Palm** → Terracotta primary + Coffee-ink secondary. Tertiary is the Playfair italic underline on every surface (Coffee ink on light, Light on deep). The per-surface hover-color values are kept only as the `arrow={false}` fallback (see Hover/press) — by default hover is the arrow-slide, not a color swap.

**Transparency & blur.** Used sparingly: gradient *protection* overlays on photos for text legibility (bottom-darker), never frosted-glass panels for their own sake.

## LAYOUT & USAGE RULES — established building the Homepage

Patterns that keep pages consistent and readable; tokens live in `tokens/spacing.css`.

**The underlying rule: spacing encodes relationship, not decoration.** Two elements that read as one idea sit close together; two that don't, sit apart — every gap below is a proximity judgment, not a default. When a new pairing isn't covered by a named token yet, don't eyeball it: name the relationship first (*same idea* · *supports it* · *a new idea entirely*), then reach for the `--space-*` step sized to that call. The gap belongs to the relationship, not to either element individually — apply it once, as margin on the element that **follows**, never split symmetrically across both sides. (Specimen: `guidelines/spacing-relationships.html`.)

- **Section rhythm.** One standardized vertical padding on every major section — `--section-pad-y` (104px; \~84px mobile). No more ad-hoc 100–140px.
- **Page gutter & width.** Every section aligns its content to a shared `--content-max` (1280px) with a `--section-pad-x` gutter (56px; 22px mobile). Full-bleed carousels still *begin* at that gutter so left/right margins line up down the whole page.
- **Heading → content gap.** A standard `--heading-gap` (72px) between a section heading and its content block.
- **Optical trim.** Line-height reserves space for a font's declared metrics, not for what actually gets inked — an all-caps 11px eyebrow never touches its font's descender allowance, so `--trim-eyebrow-bottom` (`tokens/typography.css`) reclaims it in `SectionHeading`: the authored 16px reads as 16px, not 16px-plus-hidden-leading. Measured against the real self-hosted faces and torture-tested against accented capitals (Á/É/Í/Ó/Ú/Ñ) so Spanish copy never clips; the display heading's own slack tested negligible once real descenders are accounted for, so it's left untouched — not every seam needs correcting.
- **No orphaned words.** A wrapped heading never leaves a single word alone on the last line — `SectionHeading`'s `<h2>` and `JourneySection`'s title both carry `text-wrap: pretty` (browser-native orphan control) as the default. For a title long enough to be AT RISK of an awkward break in its own column (e.g. "Sierra Nevada de Santa Marta" in `JourneySection`'s \~45%-width panel), don't rely on `pretty` alone — size the type to actually **fit that string on one line** at the column's real width, checked against real copy, not lorem ipsum. This is also why a long `JourneySection` title renders as **plain, single-colour text** rather than reaching for the `<em>` accent-word convention: splitting a tight-fitting line into two colours/styles reads as two lines even when it isn't, and the accent's italic swap can be the difference that pushes a borderline line to wrap. Short titles (e.g. "The *Eje* Cafetero") still take the accent freely — there's room to spare.
- **Readable copy contrast.** Captions, subtitles and helper / instructional text meant to be *read* use `--coffee` or `--coffee-90` on Light/Coconut — never the faint `--coffee-70` / `--coffee-55` for full sentences (those are for labels / metadata only).
- **Text over photography.** Always `--light` at full opacity (never reduced) **plus** a smooth bottom scrim gradient (transparent → dark, eased over the bottom \~half, no hard band). Text-shadow alone is not enough on bright images.
- **Icon / arrow buttons.** Never hover to a fill equal to the glyph colour (Coffee glyph + Coffee fill = invisible). Flip the glyph to `--light` on hover; since the inline base colour beats a `:hover` rule, mark the hover colour `!important`.
- **Carousels show position.** A row of **dots** (one per slide) sits with the ‹ › arrows: the active dot widens to a 22px pill at full opacity, inactive are 7px at 0.3, and dots are clickable (smooth-scroll that slide to the start). Size cards so the **next card peeks**. Dot colour follows the surface — `--coffee` on light, `--palm` on deep Coffee. **Adopted mechanism (decided):** the journey carousel is **Coverflow** — 3-D spin, the centre card in the light, neighbours receding in shadow — with a **Rich** caption, **Palm** accent, **1× type scale**, and a **“Coming soon”** badge on not-yet-live journeys. It loops infinitely (no dead end). Reference + the other mechanisms it was chosen over live in `explorations/journey-carousel-sections.html` (`#coverflow`).
- **Flagship journey sections (decided).** A complete journey section — one of the two flagship destinations, full-width — is the **booking-panel** format: a photo gallery (crossfade, arrows, a running count, a thumbnail strip) beside a flush, **no-card** product panel (eyebrow, title, teaser, a price block, highlights, a full-width primary CTA). Chosen out of seven compared compositions — split, overlapping card, numbered index, magazine spread, centered coverflow, full-bleed immersive (discarded, low photo contrast) — plus a boxed "recuadro" panel treatment, also tried and dropped in favor of the flush copy. The two flagship journeys **always alternate**: Coconut (photo left) then Coffee — **mirrored**, photo right, text flipped to Light/Palm — so they read as two distinct sections, never a repeat. The title takes the standard `<em>` accent-word convention only when short enough to spare the room; a long title (e.g. "Sierra Nevada de Santa Marta") renders plain and single-colour instead, sized to fit the panel's column on one line — see the no-orphans rule above. Ships as `JourneySection` (`components/content/`); reference + the mechanisms it beat: `explorations/journey-section-formats.html` (#07 Booking panel).
- **Alignment discipline** (recurring source of bugs — enforce it). **(a) Inside a left-aligned lockup**, every part — eyebrow, heading, subtitle, body — shares the **same left edge**. Never re-center a child with `margin: … auto …` or `text-align` inside a left-aligned block (this was a real bug: `SectionHeading`'s subtitle used `margin: 18px auto 0`, which optically centered it under a left-aligned heading — now gated on `align`). **(b) Columns side by side** (text next to media) **align their tops** — `align-items: flex-start`, not `center` — unless optical centering is the deliberate intent. Mismatched tops are the most common layout defect.
- **Botanical illustrations have gravity.** A plant illustration that reads as *growing* (banana, palm, fronds) must **stand on a section edge as if that edge were the floor** — anchor it to the section's bottom (`bottom: 0`, `position: absolute` in an `overflow: hidden` section), never floating in mid-air (it looks unmoored). The one sanctioned exception is a **seam botanical**: a leaf deliberately straddling the boundary *between* two sections, half in each, to tie them together — the monstera between two Coconut sections, and the banana plant climbing out of the Palm Final-CTA into the Coconut FAQ above it (`templates/website/sections.jsx` — a zero-height wrapper positioned exactly at the DOM seam, the illustration `top`-offset negative so it pokes past it by a fixed pixel amount regardless of either section's actual height). That one is anchored to the seam, not the floor.
- **Header — the navigation bar (decided).** Fixed as **A1**: logo-left · nav-center · lang + **Enquire Now** right — the **CTA is never on the left** — leading with the **horizontal** logo lockup. The bar is **sticky**; past ~120px it **collapses to the Terracotta stamp pill** (the `stamp-coconut` seal), morphing over 500ms, and tapping the pill returns to top. Ratified from `explorations/navbar-variations.html` (structure **A1** · **horizontal** lockup · scroll **C1**); the `Header` component renders the resting state and the specimen card shows both states. Its Enquire Now CTA is the one button in the system rendered with **`arrow={false}`** — a plain color-change hover, not the arrow-slide (see Hover/press).

## ICONOGRAPHY

Soul to Soul leans on **organic, hand-made marks rather than a UI icon font** — there is no functional glyph set as the centerpiece. Per the brandbook (§07), icons are an **encouraged graphic resource**: they may support text as bullets, build backgrounds, or illustrate a specific concept, and **multiple icons can be combined**, always in a clean, aesthetic composition. Two distinct icon styles exist alongside the logo and illustration libraries:

1. **The logo system** — `assets/logos/`: a **five-variation system** built on the eye mark, each shipped in `currentColor` + pre-tinted `-coffee`/`-light` (CSS masking renders unreliably in some contexts, so use the tinted files as plain `<img>`). **Horizontal** (`logo-horizontal*.svg`, ≈4.24:1 — cropped tight to the artwork) is the default whenever there's room for the full lockup; **vertical** (`vertical*.svg`, eye over wordmark) when it fits better; **logotype** (`logotype*.svg`) is the wordmark alone; **isotype** (`isotype*.svg`, the eye alone) is the fallback when space is tight; and the **stamp** (`stamp*.svg`, the abstract sun-in-blob seal — lives inside the scroll-collapsed Terracotta pill) is for special, abstract moments where the detailed eye would feel heavy or compete. *Travel / Journal* session sub-lockups reinforce a section, used rarely and usually only on explicit instruction (assets not yet in `assets/` — see CAVEATS). **Always SVG, brand palette only, never effects/distortion**, clear space = the cap-height of "Soul", applied by the consumer via CSS margins — **the SVGs are cropped tight to the artwork with no baked-in padding** (add breathing room via CSS; don't expect it in the file). **All five are generated from the designer's canonical editable masters kept in `assets/logos/source/`** (`master-stamp.svg` = brandbook export -16, `master-isotype.svg` = -17, `master-vertical.svg` = -18, `master-horizontal.svg` = -20); **rebuild only from those — never re-composite a lockup from separate parts, and never resurrect the old stale `325 185…` files.** Tight viewBoxes: horizontal `341 200 1311 309`, vertical `185 289 710 504`, isotype `248 404 748 579`, logotype `840 314 812 89` (the wordmark group lifted from the horizontal master), stamp `354 438 537 514`. (Base file = `currentColor` for mask/inline; every `-coffee`/`-light`/`-coconut` variant hardcodes its fill — stamp ships `-coconut` in place of `-light`.) See `guidelines/brand-logos.html`.
2. **Ancestral symbols (stamp / linocut style)** — `assets/symbols/`: a hand-carved, weathered set (sun spiral, ancestral spiral, tropical palm, moon-sun, hand spiral, vessel-of-flowers, wild rose, zen stones, codex serpent, plus seal variants) with a rough block-print texture. Used as section marks, dividers, seals and Instagram accents — e.g. the three "How we travel" pillars (the **fixed value-prop map**: *Balance* → zen stones `piedras-zen`, *Connection* → hand spiral `mano-espiral`, *Firsthand* → vessel-of-flowers `vasija-flores` — reuse these consistently wherever the pillars appear). **"Firsthand" retired "Craft"** (2026 — "hand-picked"/"curated"/"rootedness" were all tried and rejected for not tying back to the homepage Intro's own line, which keeps "hand-picked experiences" in its prose: *every corner walked by us, every detail chosen in person*. "Firsthand" is the deepened, single-word continuation of that same line). The pillars ship as the **baseline 3-up** (eyebrow + heading + three symbols in a row), heading words all plain (no italic/terracotta accent on "firsthand"), on **either Coconut or Light** chosen by the page's Coconut↔Light rhythm. Source SVGs use a `.st0` class with no fill; pre-tinted `-terracotta` / `-coffee` / `-palm` variants are shipped for use as plain `<img>`. *(A second, looser **hand-drawn line** icon style — single-stroke citrus, palm, banana, daisy, leaf, flowers — also appears in the brandbook (§07, P.42); those line glyphs are not yet in `assets/` — see CAVEATS.)*
3. **Watercolor illustrations** — `assets/illustrations/`: banana plant, jaguar, sea turtle, coconut, cacao pod, monstera and more. The brand's signature organic imagery, not icons — used as focal art inside frames and email headers.

For the rare functional glyph (WhatsApp, mail, carousel arrows, the FAQ "+"), use a single simple inline mark in Palm (WhatsApp keeps its official green `#25D366`). No third-party icon library is bundled; if one is ever needed, match a thin single-weight line set and document it here.

**Review / rating stars.** Use the recognisable ★ star glyph, but always in brand **Palm gold** (`--palm`) — *never* the source platform's own colour (Tripadvisor / Trustpilot green). The `Quote` component takes `rating` + `source` and renders this automatically: gold stars + a muted "Verified review · {source}" label. The recognisable shape carries the trust cue; the brand colour keeps it ours.

**Textures & organic shapes** (brandbook §07, P.43–44) round out the graphic-resource kit: subtle, low-noise **textures** (paper, watercolor, natural leaf-shadow) sit behind content within the brand palette, never competing with text — paper (`paper-light.jpg`), a **9-piece watercolor-wash set** (`watercolor-01–09.jpg`) and the **natural leaf-shadow** (`leaf-shadow.jpg`) now ship in `assets/textures/` (use at low opacity behind content, see `guidelines/brand-textures.html`); **organic shapes** come in two grades — *simple* blobs that mask photography and add dynamism, and *more detailed / structured* shapes reserved for large-format prints and background compositions. The **structured / large-format** set (11 shapes × currentColor + coffee/terracotta/palm tints) ships in `assets/shapes/large/` (see `guidelines/brand-shapes.html`); the **simple photo-mask blobs** (7 hand-painted PNGs with real alpha — mask photography into the silhouette or use as solid accents) ship in `assets/shapes/simple/` (see `guidelines/brand-shapes-simple.html`). Both grades are now in the system.

**When to reach for an organic shape — the trigger (this was the gap; shapes shipped as specimens with no “use it HERE” hook, so they got skipped).** The brandbook's own rule is *“organic frames for photos, not rectangles”* — so the two grades split cleanly. **Quick rule: a photograph is masked into a *simple* blob (`shapes/simple/`); a *structured / large-format* shape (`shapes/large/`) is a colour field for text — full-bleed, or a quiet backing behind it — but never over a photo.**

- **Simple blobs — frame a photo.** Reach for one when a *single* photo in a view should feel soft and human: a hero portrait, a host/founder shot, one featured image, a social post. Mask the photo into the silhouette (pre-composited PNG, or CSS `mask-image` over a rectangular photo). **Not** for photo grids, carousels or hub-city cards (rectangular rhythm + shared alignment carry those), and **not** under text (a scrim needs straight edges). One masked photo per view; an illustration never overlaps it (composition rule 1).
- **Large-format structured — two registers, both *under* text, never over a photo.**
  - **① Full-bleed field** (the default for a "background piece"). The shape *is* the background: scale it up so it **fills the frame and bleeds off all four edges**, at **full opacity** in a single brand tint (terracotta/coffee/palm) — the base colour reads as **organic negative space** and the text sits **on the solid field**. **Every edge of the frame must be in contact with the figure**: nudge it up/down/side, or zoom a hair, until no border is left uncovered and **no straight edge of the shape is parked just inside an edge** (that looks raw). Seat the **whole text block on one solid lobe** of the shape so no line crosses the figure/ground boundary — and keep a **safe gap from that boundary** (treat it like the frame edge: no closer than the layout safe margin, **≈7.5% of the frame / \~80px at 1080**). When the shape already reads well, **don't reframe it to fit centred text — move the text**: set it flush-left/right/centred and shift it laterally/vertically onto whichever lobe is clear (easier than re-cropping a good figure). **Never** cornered, centered, contained or shrunk to a small accent. *(Brandbook P.03 / P.45; reference build: `explorations/instagram-cocora.html` treatment 06.)*
  - **② Quiet backing** (the **`Callout`** device). When a *flat* surface would otherwise be a plain colour behind a feature beat — a section opener, a pull-quote, a CTA, a cover — drop in **one** shape, anchored to a corner and bleeding off, a single tint at **0.06–0.14 opacity**, *behind* the words. Interchangeable with a watercolor texture or an ancestral-symbol seal in that "quiet thing behind the words" slot — pick **one**, never stack. **Decided for the `Callout`:** the emphasis block varies its quiet backing between two registers — an **ancestral symbol seal** (`symbolSrc`, ~0.08 · treatment 03) and a **faint watercolour illustration** like the monstera (`illustrationSrc`, ~0.14 · treatment 13); the large-format **shape** (`shapeSrc`) stays available. Reference: `explorations/callouts-variations.html`.
  - Either register: **one shape per view**, **never over a photograph** (it fights the image).

**Dose (rules 1 & 4): one backing per view.** A large-format shape counts as the piece's *bold bet* — if a photograph, illustration or symbol is already carrying the moment, the shape rests. The **`Callout`** component (`components/content/`) wires a quiet backing in behind a quote or statement at the right opacity and tint — its **decided** registers are an ancestral **symbol** (`symbolSrc`) or a faint **illustration** (`illustrationSrc`), with the large-format **shape** (`shapeSrc`) still available — so it's the easiest correct way to use them.

## How to use

1. Link `styles.css` once. 2. Read this file + `docs/BRAND.md` from the source codebase for the philosophy. 3. Compose from the bundle (`window.SoulToSoulDesignSystem_643e48`) — don't re-implement primitives. 4. Preserve the palette, the adaptive button rule, the type hierarchy, the background rhythm, and the hushpitality feel. Lead with **real photography** (the primary visual focus); keep illustrations, symbols and textures as secondary accents. **Never** use FOMO/countdowns, wellness clichés, generic-purple gradients, or decorative emoji.
