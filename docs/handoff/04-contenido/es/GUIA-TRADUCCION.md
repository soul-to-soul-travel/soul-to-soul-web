# Guía de traducción EN → ES — sitio Soul to Soul Travel

Read this whole file before translating. Then read `journey-page-communication-guidelines.md` in this same folder.

## Qué se traduce
- Only the copy that is published on the website: headings, eyebrows, body text, buttons, captions, alt text, form labels, FAQ questions and answers.
- Do NOT translate internal material, such as "Notas de trabajo", "Brief de fotografía", internal notes or "not for the traveler" notes. List those parts as "[NO SE TRADUCE — material interno]".
- If a source text is already in Spanish, it is internal. Mark it the same way.

## Registro y voz
- Use neutral Latin American Spanish, natural for a Colombian brand. Address the reader as **tú**, never "usted" and never "vos".
- The voice is warm, close, honest and unhurried, like a friend who lives in the place. It is not a salesperson or a wellness coach.
- Keep the rhythm: short sentences stay short.
- Translate the meaning, not word by word. A poetic line must still sound natural in Spanish.

## Vocabulario fijo
- journey → viaje (never "tour" and never "paquete")
- host → anfitrión / anfitriona (never "guía")
- travel designer → diseñadora de viajes / diseñador de viajes
- Enquire Now → Escríbenos
- Get in Touch → Hablemos
- Each journey begins with a conversation. → Cada viaje empieza con una conversación.
- Keep Seeking → do not translate. It is the tagline.
- Firsthand → De primera mano
- Balance → Equilibrio
- Connection → Conexión
- A slow letter, once a month → Una carta sin prisa, una vez al mes
- Journey names [DECISIÓN 2026-10-26]: "Coffee Region Journey" → "Región Cafetera" and "Bogotá Journey" → "Bogotá". The old names Kabai and Bacatá are retired and must not appear in published copy; where a source still has them, flag it with [POR REESCRIBIR]. Place names stay in Spanish: Eje Cafetero, Valle de Cocora, Sierra Nevada.
- Prices and units: "USD 4,200" becomes "USD 4.200". Use day/month order for dates.

## Prohibido
- Never use these phrases: "todo incluido", "todo resuelto", "escápate del estrés", "experiencia inolvidable", "lugares mágicos", "experiencia única", "aventura extrema", or "transformación" promised as a result.
- Never write the word "Raíz" in published copy. If the source has it in a signature or similar place, flag it with [REVISAR: "Raíz" no debe aparecer en público].
- No emojis.

## Formato del archivo de salida
- Markdown, in Spanish.
- First line: `# <Página> — copy en español`
- Then this block:
  `> [TRADUCCIÓN PRELIMINAR — REVISAR] Traducido por Claude el 2026-10-26 a partir de <archivo fuente>. Pendiente de revisión del equipo.`
- Follow the source's order and section names. Use section headings like `## 01 · Hero`.
- For each text, write the field label and the Spanish text. Include the English original only where the translation took real freedom, as a line `EN: ...` below it.
- Where the source is empty or a placeholder (TBD, [VACÍO EN NOTION], [PENDIENTE]), write `[PENDIENTE EN EL ORIGINAL]`. Do not invent copy.
- Add an extra tag only where there is a real doubt: [REVISAR: motivo].
